시스템 top view — 32 col-parallel dataflow
GEMM 의 32 col 출력 → RMW[32] → bank[32] · col j → RMW[j] → bank[j] (충돌 0) · 매 cycle 최대 32 R/W 병렬
분기 — GEMM 출력 → 32 lane

out_accumulate[c×60] 의 60-bit slice 를 mode 별 디코드: A8 = 1 × 21b, A4 = 2 × 18b, A2 = 4 × 15b. INT32 sign-ext + 9b scale 과 묶여 RMW[c] 로.

변환 + 누적 — 32 RMW 동시 동작

RMW = stateless 5-cy pipe. in_GEMM+scale → FP32, 이전 in_SRAM 과 add → out_RMW. 백프레셔 없이 매 cycle 32 개 RMW 가 독립 진행.

저장 — 32 bank · dedicated port

col j → bank j (충돌 0). CEB[j]=0,WEB[j]=1 = read, WEB[j]=0 = write. read latency 1 cy. 같은 cycle 에 32 bank 독립 R/W 가능.

★ MIXED-PREC KEY

같은 cycle 의 32 row = 같은 K-block 의 32 K-element → K-block 단위 W_PREC 자유 설정 가능. row=M 으로 가정하면 "M 별 W_PREC 다르면 dataflow 깨짐" 라는 잘못된 결론 빠짐. 실제로는 row=K 라 자연스레 K-block 단위로 묶임.

★ MODE 별 lane fanout (col 당)

★ 왜 ping-pong

한 K-tile 의 MAC 진행 중 다음 K-tile 의 activation 을 미리 load 해야 throughput 끊김 없음. 현재 PE 가 읽는 buffer (broadcast) 와 load 중인 buffer 를 항상 반대편으로 둠 → K-tile 경계마다 in_control toggle 만으로 자동 swap.

★ 왜 Lane_ctrl 이 4-bit mask

각 PE 의 adder_lane[k].ctrl 가 mode-dep 행동 (sign-ext / clamp / pass-through). 4-bit lane mask 면 PE 안에서 mode 별 분기 없이 lane enable 만으로 처리 가능 → critical path 단축. station 이 mode (Mode_oh) 와 lane mask (Lane_ctrl) 둘 다 caching.

SRAM banking — col j → bank j, 충돌 0
sram_1rw_banked_mp · 32 bank 각 1024 word × 32-bit · 128×128 워크로드 = 512 word/bank
FP32 word 의 SRAM flat 주소 → (bank, word) 분해

flat = m × N + n
bank = flat % 32 = n % 32 (n < 32)
word = flat // 32

→ 같은 m, 다른 n=32k+c 의 결과는 모두 bank c 로
★ COL-PARALLEL 의 결과

매 cycle 최대 32 개 독립 R/W 가능. col j 의 RMW[j] 가 자기 bank[j] 만 건드림 → 하드웨어에서 bank-conflict resolver 가 필요 없음.
(mapping callable: MXP_Tools/mxp_tools/hwio.py::interleaved_row_major_32bank)

1) Capture

out_fire[c] ↑ 마다 (int32, scale, flat_addr) 디코드 → per-col FIFO push. mode 별 lane 수 만큼 entry (A8=1, A4=2, A2=4).

2) R-M-W FSM (state 0–6)

state 0: R 발사 → 1: Q 도착 → 2: RMW 입력 → 4: 8cy wait → 5: W 발사 → 6: pop. 총 ~10 cy/entry. 32 col 동시 진행.

3) Bit-exact 검증

RMW out_RMW = INT psum × 2^(scale−127) + 이전 FP32. 외부 compare 가 MXP_Tools golden npz 와 bank dump 를 word-by-word 매칭.
